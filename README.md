# 📌 About Project

Zappit is a **hyperlocal quick-commerce platform** designed to provide ultra-fast delivery of everyday essentials. The system enables users to order products like groceries, snacks, beverages, milk products, and stationery while supporting secure payment methods including **UPI and Cash on Delivery (COD).**

The platform focuses on:

- ⚡ Quick delivery
- 🛒 Smart product ordering
- 💳 Secure payments
- 📍 Hyperlocal services
- 📱 User-friendly interface
